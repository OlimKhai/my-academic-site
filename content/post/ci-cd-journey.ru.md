Один из самых ценных навыков, который я освоил на этой неделе — **Continuous Integration и Continuous Deployment (CI/CD)**. Вместо ручной загрузки файлов на сервер, я настроил GitHub Actions для автоматической сборки и публикации сайта.

## ��� Как это работает
1. Я пишу контент локально в Markdown.
2. Отправляю изменения в GitHub через `git push`.
3. GitHub Actions запускает workflow, который:
   - Устанавливает Hugo
   - Собирает статический сайт
   - Публикует его на GitHub Pages
4. Через несколько минут изменения становятся доступными онлайн!

## ���️ Проблемы и решения
- **Ошибка Node Options**: Исправлено путем удаления конфликтующих переменных среды в workflow.
- **Несоответствие версии Hugo**: Обновил `HUGO_VERSION` до `0.161.0` для соответствия требованиям темы HugoBlox.
- **Конфликты workflow**: Удалил дублирующиеся файлы workflow, чтобы предотвратить конфликты.

## ✅ Результат
Теперь я могу сосредоточиться на **написании контента**, а не на управлении развертыванием. Это основной принцип DevOps: автоматизируй рутину!
